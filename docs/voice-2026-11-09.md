# Browser narration adapter

`assets/ui/errata/voice.js` provides `window.ErrataVoice`, a free browser-native `speechSynthesis` layer. It has no remote service, network call, key, package, or audio asset requirement. Browser and operating-system voice availability varies; the adapter refreshes voices after `voiceschanged` and falls back by language when a saved voice is missing or incompatible.

## API

```js
ErrataVoice.speak(text, { role, lang, interrupt });
ErrataVoice.cancel();
ErrataVoice.set({ enabled, muted, volume, voiceURI });
ErrataVoice.getSettings();
ErrataVoice.voices; // [{ voiceURI, name, lang, default }]
ErrataVoice.voiceChoice; // saved voiceURI
ErrataVoice.volume; // 0..1
ErrataVoice.muted; // true when muted or disabled
```

Roles are `narrative`/`story` (Turkish by default), `boss` (English by default), and `quiz`/`word` (English pronunciation by default). Explicit `lang` takes precedence. Boss speech uses a modestly slower pace and slightly lower pitch; quiz pronunciation slows clearly without lowering pitch. Narration is split at sentence and phrase boundaries with brief pauses. A new call interrupts by default; cancellation invalidates pending chunk callbacks. `interrupt: false` preserves the browser queue. Muting or disabling cancels current speech. Settings persist defensively in `localStorage` under `lexicon_voice_settings_v1`.

## Integration points for `game.js` / `index.html`

1. Load `<script src="assets/ui/errata/voice.js"></script>` after the inline setup block and before `game.js` in `index.html` (currently the script sequence is around lines 579–583). Add/update a cache query string with the project's normal asset versioning.
2. In `game.js`, replace the internals of `speakGameText(text, options = {})` with `return ErrataVoice.speak(text, { role: options.role === 'word' ? 'quiz' : options.role, lang: options.lang, interrupt: true });`. Preserve `gameSpeechState.text/options` assignments if the replay button uses them; leave `replayGameSpeech()` calling `speakGameText()` so it automatically uses the adapter.
3. In `stopGameSpeech()`, call `ErrataVoice.cancel()` (in place of directly calling `speechSynthesis.cancel()`) so the adapter also invalidates outstanding phrase callbacks before replay or a story panel transition.
4. `speakBossVoiceLine(eventKey, text)` already calls `speakGameText(text, { lang: 'en-US', role: 'boss' })`; keep its event deduplication and route the wrapper through `ErrataVoice` as above.
5. Story narration call sites (`speakGameText(chapter.narration, { lang: 'tr-TR', role: 'narrator' })` near line 2993 and dialogue near line 3888) use the same adapter wrapper. The `narrator` role receives the story profile and explicit Turkish locale. Dialogue may specify `boss` or `character`; the adapter intentionally keeps the character profile restrained.
6. Quiz button and immediate quiz speech call `speakGameText(card.word, { lang: 'en-US', role: 'word' })` near line 7360; map `word` to `quiz` as above to retain the dedicated pronunciation profile.
7. Extend the generated audio settings section in `assets/ui/errata/interface.js` near the current SFX/music rows: add a `voice-muted` checkbox mapped to `ErrataVoice.set({ muted: checked })`, a `voice-volume` range mapped to `ErrataVoice.set({ volume })`, and a voice `<select>` populated from `ErrataVoice.voices` with `voiceURI` as option value and `name · lang` as visible label. Refresh that option list on `speechSynthesis`'s `voiceschanged` event and preserve the selected `ErrataVoice.voiceChoice`; use the default/fallback when it is absent. Add an `voice-enabled` checkbox if users need a separate enable switch; `muted` is the simple sound toggle. Keep labels/descriptions in Turkish and connect controls to `aria-label`/`aria-valuetext` like adjacent controls.

`voice.css` is not needed: the settings controls can use existing `.settings-row` / `.audio-setting-control` styles. The existing story replay and quiz pronunciation buttons need no markup changes.

## Verification

Run `node test/voice.cjs`. The deterministic harness checks English/Turkish voice choice, incompatible-choice fallback, role pacing, chunk advancement, stale callback cancellation, mute, volume, and persisted settings. It cannot measure the sound quality of the locally installed operating-system voices; listen on supported target browsers to judge that separately.

# Word bank data attribution

The word records and Turkish glosses in `questions.json` combine the game's original 200 authored question records with 800 added vocabulary entries. The added entries use these openly licensed sources for headwords, Turkish glosses, CEFR level hints, and example vocabulary selection:

- **FreeDict English–Turkish dictionary data**, distributed by KOReader Dictionaries, CC BY-SA 4.0. Its upstream source notes include Princeton WordNet 3.0 and Wiktionary material collected through kaikki.org / wiktextract. <https://danielgregorini.github.io/koreader-dicts/en/downloads/>
- **Words-CEFR-Dataset**, Maximax67, MIT License; its README credits CEFR-J/Tono and Google Ngrams. Used for A1–B2 level selection. <https://github.com/Maximax67/Words-CEFR-Dataset>
- **Octanove Vocabulary Profile C1/C2**, Open Language Profiles, version 1.0, CC BY-SA 4.0. Used to select advanced headwords. <https://github.com/openlanguageprofiles/olp-en-cefrj/blob/master/octanove-vocabulary-profile-c1c2-1.0.csv>

The derived vocabulary records, Turkish glosses, level labels, and authored semantic enemy/buff fields in the shared word bank are provided under **CC BY-SA 4.0** to comply with the share-alike source data. Original authored question records retain their project authorship. The application code is not relicensed by this data notice.
